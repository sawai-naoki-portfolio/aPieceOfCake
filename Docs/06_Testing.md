# 06. テスト仕様

## 1. 方針

- ルール（`PieceOfCake.Core`）は Unity に依存しないため、**EditMode テストだけで高速に網羅** します（53 件、約 1 秒）。
- 全ステージを **参照解法で自動プレイ** し、★3・ミス 0 でクリアできることを毎回確認します。
- 同じ解法を HTML 試作品でも実行して得た「おとどけしたフレーム番号」と照合し、**移植がフレーム単位で正確** であることを保証します。
- 表示・UI は Play モードで目視確認し、[Screenshots](Screenshots) に記録しています。

## 2. 実行方法

- Unity：**Window ▸ General ▸ Test Runner ▸ EditMode ▸ Run All**
- コマンドライン（CI 用）：

```bat
"C:\Program Files\Unity\Hub\Editor\6000.6.6f1\Editor\Unity.exe" -batchmode -nographics ^
  -projectPath "<プロジェクトのフォルダ>" ^
  -runTests -testPlatform EditMode -testResults results.xml -logFile -
```

## 3. テスト一覧

| ファイル | 内容 |
|---|---|
| `StageSolutionTests` | 5 ステージを参照解法でプレイ：★3・ミス 0・完了（5 件）／試作品とおとどけフレームが一致（5 件）／同じ入力で同じ結果（決定性） |

| `LevelDataTests` | 同梱 5 ステージが正しい、大文字/小文字のつながり、ごちゅうもんは単独ピース、看板の並び順、不正マップの拒否（8 種）、サイズ上限、負の par、不正 JSON の拒否（5 種） |
